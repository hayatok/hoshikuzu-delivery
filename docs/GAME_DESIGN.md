# ゲームデザイン: 星屑デリバリー

## アイデア検討

候補アイデアを「短時間で完成できること」「Blenderアセットが映えること」「1画面でルールが伝わること」で評価し、本作を選定した。

| 候補 | 概要 | 不採用/採用理由 |
|---|---|---|
| 星屑デリバリー（採用） | 浮島で星屑を集めて灯台へ配達 | 収集＋ゴールが明確。島・灯台・ドローン等、ローポリアセットと好相性 |
| 浮島レース | チェックポイントを周回 | コース設計とAI/ラップ判定で工数が膨らむ |
| 島づくりサンドボックス | 建物を配置して島を育てる | UIと保存機能が必要で短期完成に不向き |

コンセプト: 「夕暮れの浮島の配達屋さん」。かわいいホバードローンを操り、落ちている星屑を拾って灯台に届ける、ほのぼの×タイムアタック。

## ルール

- 星屑は島内に8個。ドローンが近づくと回収。
- 8個集めた状態で灯台（ゴール）に近づくとクリア。残り時間を表示。
- 制限時間120秒を過ぎるとゲームオーバー。集めた数を表示。
- リスタートボタンで即再挑戦可能。
- 木・岩・家・灯台は半径ベースの当たり判定で侵入不可。島の縁（半径29）から外に出られない。

## 操作

- WASD / 矢印キー: 移動（カメラはドローンを滑らかに追尾）
- Shift: ダッシュ（2倍速）
- Space: ホバージャンプ

## アセット一覧（Blender生成: assets/scripts/make_assets.py）

| tree.glb | ローポリ松の木 |
| rock.glb | 岩 |
| house.glb | 小さな家（発光窓・煙突） |

ソース .blend は assets/source/ に保存。プレビューは preview.png / docs/preview.png。

## 技術

- Three.js (GLTFLoader で GLB 読み込み、読み込み失敗時は簡易ジオメトリにフォールバック)
- Vite（開発サーバー / ビルド）
- Blender 4.2 LTS ヘッドレス（Python スクリプトで全アセットをプロシージャル生成、Cycles でプレビューレンダリング）
- HUD・画面遷移は素の HTML/CSS（日本語UI）
